# Data license and attribution

Contains information from Banco Central do Brasil's public databases:

- [Expectativas de Mercado — Focus](https://dadosabertos.bcb.gov.br/dataset/expectativas-mercado).
- [SGS 432 — Taxa de juros: Meta Selic definida pelo Copom](https://dadosabertos.bcb.gov.br/dataset/432-taxa-de-juros---meta-selic-definida-pelo-copom).
- [SGS 1 — Taxa de câmbio: Livre, Dólar americano (venda), diário](https://dadosabertos.bcb.gov.br/dataset/1-taxa-de-cambio---livre---dolar-americano-venda---diario).

weekly alignment, feature construction, and evaluation. The snapshot manifest
records source request URLs and file hashes; the source code documents the
transformations. Banco Central do Brasil does not endorse these modifications,
models, or conclusions.
